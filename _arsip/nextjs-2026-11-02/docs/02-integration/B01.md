# B01 — FR-07 autentikasi dan guard peran

Tanggal: 1 November 2026

## Implementasi

- `POST /api/auth/masuk` memvalidasi request dengan Zod, memberi respons kredensial generik, dan mengeluarkan cookie `httpOnly` tanpa mengirim token di JSON.
- Lima kegagalan pada akun dalam jendela 10 menit memicu lockout 10 menit. Kunci percobaan disimpan sebagai HMAC email, dan pembaruan counter memakai transaksi serta row lock.
- Sesi memakai JWT dengan idle timeout 15 menit dan batas absolut tujuh hari. Tabel `sessions` menyimpan hash session identifier; guard Route Handler memeriksa sesi di PostgreSQL.
- Logout menghapus sesi server-side; token lama ditolak oleh guard. `GET /api/auth/saya` mengembalikan identitas minimum dan memperbarui cookie untuk sesi yang masih aktif.
- Proxy mengizinkan request API mencapai Route Handler agar galat autentikasi berbentuk JSON 401. Halaman inti tetap mengarahkan tamu ke login; otorisasi API dilakukan oleh guard di handler.
- Migrasi `0004_auth_login_attempts.sql` menambahkan penyimpanan lockout. Konfigurasi Drizzle hanya memuat tiga modul skema agar file test di direktori skema tidak ikut diimpor.

## Hasil review dan sisa

Perbaikan B01 yang disetujui telah diterapkan:

- Route Handler terautentikasi dapat memakai `attachRefreshedSessionCookie`
  agar aktivitas memperpanjang idle timeout sampai batas absolut tujuh hari.
- Logout tanpa sesi menghasilkan 401.
- Sesi tidak valid memakai kode `SESSION_EXPIRED`.
- JSON login rusak menghasilkan `422 VALIDATION_ERROR`.
- Teardown menghapus record percobaan email tidak dikenal.
- Verifikasi DB berisi 10/10 test.

Sisa teknis: perhitungan deadline auth masih berada di modul auth dan belum
seluruhnya dipusatkan ke `src/lib/waktu-wib.ts`. Pemindahan helper tersebut
memerlukan perubahan di luar `paths` B01. Jalur Proxy meneruskan API ke handler;
otorisasi tetap dilakukan handler karena Proxy tidak memeriksa sesi server.

B01 tetap `doing` karena belum ada commit, sesuai keputusan pemilik untuk
menunda commit. Login menerima email/password saja dan menolak field tambahan
melalui Zod strict.
