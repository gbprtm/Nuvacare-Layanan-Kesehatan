- **Sistem Operasi:** Windows (x64)
- **PHP:** `PHP 8.4.27 (cli)` dengan ekstensi `pdo_pgsql` dan `pgsql` aktif
- **PostgreSQL Client Tools:**
  - `pg_dump`: Tidak ditemukan di PATH Windows bawaan.
  - `pg_restore`: Tidak ditemukan di PATH Windows bawaan.
  - `neonctl`: Terpasang via `npx neonctl` (versi `8.16.0`) untuk instant snapshot copy-on-write branch Neon.

- **Database Engine Target:** Lakebase PostgreSQL di Neon (`Asia/Jakarta` WIB Clock).

```bash

```
**Hasil:**
