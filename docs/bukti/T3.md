# Bukti Tahap 3: Fitur Profil Pengguna

## Ringkasan
- Endpoint yang dibuat:
  - `GET /api/profil`: Mengambil data profil pasien dari token pengguna yang login (id, name, email, role, phone_number, birth_date, address).
  - `PATCH /api/profil`: Memperbarui data pengguna (name, phone_number, birth_date, address). Role dan email terproteksi dari perubahan.
- Pengamanan:
  - Diproteksi middleware `auth:sanctum` dan `role:pasien`.
  - Akses tanpa token ditolak 401 Unauthorized.
  - Akses oleh pengguna role `admin` ditolak 403 Forbidden.
- Frontend:
  - `public/pasien/profil.html`: Formulir profil mandiri pasien berbahasa Indonesia.
  - `public/js/pasien.js`: Mengambil data profil awal via fetch API dan mengirim pembaruan PATCH, memperbarui nama di header lokal secara reaktif.
- Pengujian:
  - `tests/Feature/ProfileApiTest.php` (4 tests passed, 7 assertions).
  - Linter: Pint passed cleanly.
