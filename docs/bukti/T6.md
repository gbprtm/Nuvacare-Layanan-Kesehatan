# Bukti Tahap 6: Arsitektur Dua Permukaan & RBAC Staf

## Ringkasan
- Konfigurasi Pemisahan Permukaan & Deployment:
  - `config/surface.php`: Mengatur mode `APP_SURFACE` (`pasien`, `staf`, `combined`) dan `STAFF_ALLOWED_IPS` opsional.
  - `config/features.php`: Mengatur feature flag `FEATURE_DOCTOR_PORTAL` (`features.doctor_portal`).
  - `config/cors.php`: Membatasi allowed origins sesuai permukaan host.
  - `vercel.json` (`APP_SURFACE=pasien`) dan `vercel.staf.json` (`APP_SURFACE=staf`) memisahkan konfigurasi deployment pasien dan staf, sementara berkas HTML dipisah ke `surfaces/pasien/*` (9 halaman) dan `surfaces/staf/*` (4 halaman) serta seluruh file HTML lama pada `public/` dihapus.
- Middleware, Prioritas & Token Ability:
  - `app/Http/Middleware/SurfaceRouteMiddleware.php`: Mengembalikan `404` bila endpoint pasien diakses pada host staf atau endpoint staf diakses pada host pasien.
  - `app/Http/Middleware/FeatureFlagMiddleware.php`: Mengembalikan `404` untuk route portal dokter dan pengajuan saat `features.doctor_portal = false`.
  - `app/Http/Middleware/StaffIpAllowlistMiddleware.php`: Mengembalikan `403` untuk IP di luar `STAFF_ALLOWED_IPS` bila daftar diisi.
  - `bootstrap/app.php`: Memprioritaskan `SurfaceRouteMiddleware`, `FeatureFlagMiddleware`, dan `StaffIpAllowlistMiddleware` sebelum `AuthenticatesRequests` agar route tersembunyi mengembalikan `404` (bukan `401`).
  - `app/Http/Middleware/SurfaceTokenMiddleware.php`: Memeriksa token ability `surface:pasien` vs `surface:staf` pada route API.
  - `app/Http/Middleware/EnsureActiveDoctorMiddleware.php` dan `app/Http/Middleware/RoleMiddleware.php`: Memvalidasi peran, status aktif akun (`disabled_at` null), dan keterhubungan baris `doctors` aktif (`is_active = true`) untuk role `dokter`.
- RBAC Gate/Policy & Autentikasi Staf:
  - `app/Policies/AppointmentPolicy.php`, `app/Policies/CancellationRequestPolicy.php`, dan `app/Providers/AppServiceProvider.php` (`manage-staff-operations`, `manage-doctor-accounts`, `doctor-portal`).
  - `app/Http/Controllers/Api/AuthController.php`: Memblokir login lintas permukaan (`403`), menolak akun dokter yang dinonaktifkan atau belum terhubung ke baris dokter aktif (`403`), dan menerbitkan Sanctum token dengan ability sesuai permukaan.
  - `app/Http/Controllers/Api/Admin/DoctorController.php`: Menambahkan provisioning akun dokter (`POST /api/admin/dokter/{id}/akun`) dan toggle akses akun + pencabutan token (`PATCH /api/admin/dokter/{id}/akun`).
- Frontend Staf:
  - `surfaces/staf/staf/login.html`, `public/js/api.js`, `public/js/auth.js`: Gerbang masuk khusus staf dengan validasi role & pengalihan berbasis `APP_SURFACE`.
