## 1. Lingkungan Runtime dan Arsitektur Data

- **PHP:** `PHP 8.4.27 (cli)` dengan `pdo_pgsql`, `pgsql`, `mbstring`, `openssl`
- **Database:** PostgreSQL Neon (branch terisolasi)
- **Ketiadaan NIK/KK by Design:**
  - Sesuai rancangan aplikasi personal klinik dan arahan pemilik, sistem **tidak dirancang untuk mengumpulkan atau mengelola NIK/KK**.
  - Formulir antarmuka Blade, Form Request, dan Model tidak memuat input atau kolom NIK/KK baru. Input yang menyelipkan `nik` atau `kk` ditolak secara eksplisit melalui aturan validasi `prohibited`.
- **Sifat Capture Murni pada Konsumsi Obat Pasien:**
  - Daftar konsumsi obat yang tampil pada antarmuka pasien merupakan rekaman snapshot/capture historis (`PatientReportedMedication`).
  - Pasien **tidak memiliki tombol/kontrol untuk mengedit atau menghapus** daftar obat tersebut secara mandiri.
- **Katalog Referensi Fornas:**
  - Dataset publik [`data/fornas/2026-11-01-A.json`](../../data/fornas/2026-11-01-A.json) diimpor ke tabel `katalog_obat_fornas` secara idempoten melalui command `app:import-medicine-catalog`.
  - Disertai metadata snapshot resmi: sumber Formularium Nasional Kemenkes RI, versi snapshot `2026-11-01-A`, cakupan snapshot parsial huruf A, dan tanggal snapshot `2026-11-01`.

## 5. Ringkasan Berkas yang Dibuat dan Diubah

1. `app/Console/Commands/ImportMedicineCatalog.php`: Command artisan untuk mengimpor snapshot Fornas dengan pencatatan metadata sumber.
2. `app/Http/Requests/Profile/UpdateProfileRequest.php`: Validasi profil fisik, kontak darurat, serta penegakan `prohibited` untuk NIK/KK dan role.
3. `app/Http/Requests/Profile/DestroyProfileRequest.php`: Validasi konfirmasi teks `HAPUS PROFIL`.
4. `app/Services/Profile/ProfileService.php`: Logika bisnis pembaruan profil mandiri, capture obat read-only, dan reset profil mandiri.
5. `app/Services/Medicines/MedicineCatalogService.php`: Layanan pencarian dan paginasi katalog obat Fornas.
6. `app/Policies/ProfilePolicy.php`: Otorisasi hak milik pasien dan isolasi profil penuh dari admin.
7. `app/Http/Controllers/Profile/ProfileController.php`: Controller profil pasien (`show`, `edit`, `update`, `destroy`).
8. `app/Http/Controllers/Profile/MedicineCatalogController.php`: Controller katalog referensi obat Fornas.
9. `routes/web.php`: Rute profil pasien (`/profil`, `/profil/ubah`) dan katalog obat publik (`/katalog-obat`).
10. `resources/views/profile/show.blade.php`: Tampilan profil mandiri, riwayat alergi kontras tinggi, kartu capture obat read-only, dan form reset profil.
11. `resources/views/profile/edit.blade.php`: Formulir pembaruan profil tanpa NIK/KK yang bekerja tanpa JavaScript.
12. `resources/views/medicines/catalog.blade.php`: Antarmuka katalog obat Fornas dengan pencarian dan disclaimer resmi.
13. `resources/views/layouts/patient.blade.php`: Integrasi tautan navigasi profil pasien dan katalog obat.
14. `resources/views/layouts/admin.blade.php`: Integrasi tautan katalog obat di header admin.
15. `resources/views/dashboards/pasien.blade.php`: Kartu pintasan profil kesehatan di beranda pasien.
16. `tests/Feature/ProfileTest.php`: 11 pengujian feature profil, capture obat, NIK/KK rejection, IDOR, dan katalog Fornas.
17. `tests/e2e/profile.spec.ts`: 1 pengujian E2E browser Chrome menyeluruh.
