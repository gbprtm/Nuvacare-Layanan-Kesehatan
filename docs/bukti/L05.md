## 1. Lingkungan Runtime dan Desain

- **PHP:** `PHP 8.4.27 (cli)` dengan `pdo_pgsql`, `pgsql`, `mbstring`, `openssl`
- **Database:** PostgreSQL Neon (branch terisolasi)
- **Desain & Aset:** Mengadopsi penuh [`DESIGN.md`](../../DESIGN.md) dan skill `antislop` (`antislop-ui`, `antislop-human`, `antislop-layoutmobile`):
  - Latar halaman: `#EEF1F6` (`--color-bg`), Permukaan: `#FFFFFF` (`--color-surface`)
  - Tombol Utama Tunggal per Layar: Hitam solid (`#111418` / `--color-ink`) dengan teks putih
  - Aksen Lime (`#D9EE4F`): Hanya untuk sorotan kontekstual tertentu, tidak digunakan sembarangan
  - Garis Tepi Kontrol: `#7A8494` (`--color-line-strong`) memenuhi kontras minimum 3:1 terhadap background
  - Tipografi Editorial Humanis: `'Newsreader'` serif untuk judul layar, `'Plus Jakarta Sans'` untuk teks/label/input dasar 16px
  - Aksesibilitas WCAG AA:
    - Minimum tap target 44x44px untuk tombol, tautan, dan elemen interaktif
    - Rasio kontras teks dasar >4.5:1
    - Skip link keyboard navigasi (`.skip-link`) menuju `#main-content`
    - Outline fokus yang jelas (`:focus-visible`) setebal 2px dengan offset 2px
    - Dukungan media query `@media (prefers-reduced-motion: reduce)`
  - Progressive Enhancement: Seluruh formulir Blade bekerja 100% tanpa JavaScript. JavaScript vanilla di `resources/js/app.js` hanya memberikan progressive enhancement untuk mencegah pengiriman ganda (*anti double-submit*).
  - Tampilan Mobile Responsif: Diuji pada viewport 360px tanpa ada horizontal overflow (`scrollWidth <= clientWidth`).

## 5. Ringkasan Berkas yang Dibuat dan Diubah

1. `resources/views/layouts/base.blade.php`: Kerangka utama HTML5, meta viewport, font Newsreader + Plus Jakarta Sans, skip link ke `#main-content`, flash message alert container.
2. `resources/views/layouts/app.blade.php`: Layout halaman umum & tamu autentikasi.
3. `resources/views/layouts/patient.blade.php`: Layout khusus portal pasien dengan header ringkas, tombol profil, dan tombol keluar.
4. `resources/views/layouts/admin.blade.php`: Layout operasional admin klinik dengan navigasi operasional, indikator peran, dan tombol keluar.
5. `resources/views/components/alert.blade.php`: Komponen pesan umpan balik (*success*, *danger*, *warning*, *info*) dengan semantic role `alert` dan status.
6. `resources/views/components/card.blade.php`: Komponen kartu konten modular.
7. `resources/views/components/empty-state.blade.php`: Komponen keadaan kosong yang informatif tanpa visual berlebihan.
8. `resources/views/dashboards/pasien.blade.php`: Integrasi komponen ke portal pasien.
9. `resources/views/dashboards/admin.blade.php`: Integrasi komponen ke portal operasional admin.
10. `resources/css/app.css`: Token desain warna, tipografi, grid responsif, kontrol fokus, gaya tombol primer/sekunder/bahaya, tap target 44px, styling skip-link, dan handling reduced motion.
11. `resources/js/app.js`: Script vanilla pencegah submit dobel secara ramah pengguna (tetap fungsional saat JS mati).
12. `tests/Feature/LayoutTest.php`: 4 pengujian feature Blade, token, layout, dan komponen.
13. `tests/e2e/layout.spec.ts`: 3 pengujian browser E2E Playwright di Google Chrome (360px viewport no-overflow, keyboard tab skip link, no-JS fallback).
