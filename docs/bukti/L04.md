## 2. Pemetaan Acceptance Criteria

| Kriteria Acceptance | Hasil Aktual | Keterangan |
|---|---|---|
| Registrasi hanya pasien (role kiriman diabaikan/ditolak) | Lulus | Mutlak disetel `'pasien'` di server, input `role=admin` diabaikan |
| Validasi kata sandi minimal 8 karakter | Lulus | Password <8 karakter ditolak dengan error bag bahasa Indonesia |
| Sembunyikan kata sandi dari old input | Lulus | Password tidak dipantulkan kembali pada formulir saat validasi gagal |
| Login & logout dengan rotasi session ID | Lulus | `session()->regenerate()` saat login, `session()->invalidate()` saat logout |
| Penegakan Server-Side Idle Timeout 15 Menit | Lulus | `EnforceIdleTimeout` memutuskan sesi setelah 900 detik tidak aktif |
| Rate limiting percobaan masuk | Lulus | Terkunci dengan status 429 setelah 5 kali percobaan berturut-turut |
| Proteksi CSRF & error bag aman | Lulus | Formulir memuat `@csrf`, mutasi tanpa token ditolak |
| Proteksi Peran (Role Guard) | Lulus | Pasien ditolak (403) saat mengakses `/admin`, tamu diarahkan ke `/masuk` |
| Pengalihan pengguna yang sudah masuk | Lulus | Akses ke `/masuk` atau `/daftar` dialihkan ke `/beranda` atau `/admin` |
| Pengujian PHPUnit AuthenticationTest | Lulus | 13 test, 57 assertions lulus 100% |
| Pengujian E2E Playwright Google Chrome | Lulus | 3 skenario browser (registrasi, login, logout, validasi) lulus |
