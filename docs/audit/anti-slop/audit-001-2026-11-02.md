# Laporan Audit Antislop & UI (Audit-001)

**Tanggal:** 2026-11-02  
**Mode:** Mode 2 (After)  
**Lingkup:** Antarmuka Frontend (`public/`), Desain CSS (`public/css/style.css`), dan Interaksi JavaScript (`public/js/`).  

---

## Daftar Temuan (Numbered Findings List)

| No | Aturan (Rule) | Prioritas | Komponen / Berkas | Alasan / Deskripsi Temuan |
|---|---|---|---|---|
| **1** | **R-39** (Accessible Semantics & Landmarks) | **HIGH** | `login.html`, `daftar.html`, `lupa-password.html`, `reset-password.html` | Halaman auth tidak memiliki landmark semantik `<main>` (hanya `<div>` di dalam `<body>`). |
| **2** | **R-39** (Single H1 Hierarchy) | **HIGH** | `pasien/janji-temu.html`, `admin/kelola-janji.html`, `admin/master-data.html` | Tidak memiliki elemen `<h1>` utama halaman; hierarki judul langsung melompat ke `<h2>`. |
| **3** | **R-25** (Color Contrast WCAG AA) | **HIGH** | `public/css/style.css` | Warna `--color-text-muted: #64748B` pada latar belakang `--color-bg: #F8FAFC` memiliki rasio kontras 4.34:1 (di bawah ambang batas minimum WCAG AA 4.5:1). Perlu disesuaikan ke `#475569` (5.8:1). |
| **4** | **R-32** (Keyboard Focus Indicator) | **HIGH** | `public/css/style.css` | Belum ada styling `:focus-visible` global untuk tautan (`<a>`) dan tombol (`<button>`) saat dinavigasi menggunakan papan ketik (Tab). |
| **5** | **R-32 & R-26** (Modal Keyboard Dismissal) | **HIGH** | `public/admin/kelola-janji.html`, `public/js/admin.js` | Modal dialog "Kelola Janji Temu" belum memiliki atribut `role="dialog"`, `aria-modal="true"`, dan belum bisa ditutup menggunakan tombol keyboard `Escape`. |
| **6** | **R-03** (Mobile Tap Target Size) | **HIGH** | `public/css/style.css` | Elemen tombol aksi kecil (`.btn-sm` dan tombol aksi kelola di tabel) memiliki tinggi efektif di bawah target sentuh minimum mobile 44px. |
| **7** | **R-39** (Reduced Motion Accessibility) | **HIGH** | `public/css/style.css` | Belum menyediakan media query `@media (prefers-reduced-motion: reduce)` untuk menghentikan animasi dan transisi bagi pengguna dengan sensitivitas gerak. |
| **8** | **R-27** (In-Modal Error Feedback) | **HIGH** | `public/admin/kelola-janji.html`, `public/js/admin.js` | Penanganan gagal simpan status janji temu pada modal admin masih menggunakan dialog browser bawaan `alert()`, bukan feedback error inline/komponen alert UI. |
| **9** | **R-39** (Interactive Affordance & Cursor) | **HIGH** | `public/css/style.css` | Status disabled form controls (`.btn:disabled`, `.form-input:disabled`) belum sepenuhnya konsisten menerapkan `cursor: not-allowed; opacity: 0.6`. |
| **10** | **R-09 / R-11** (Liveliness & Depth) | **MEDIUM** | `public/css/style.css`, `public/index.html` | Kartu layanan dan komponen tombol utama berisiko terlihat steril/flat default; perlu sentuhan kedalaman visual halus (subtle micro-interaction pada hover dan elevasi terarah). |

## Petunjuk Tindak Lanjut

Sesuai protokol **Antislop Mode 2 (After)**:
- Tidak ada berkas yang diubah sebelum Anda menyetujui daftar temuan di atas.
- Silakan tentukan nomor temuan yang ingin diperbaiki (misalnya: `"perbaiki semua"`, `"perbaiki 1-8"`, atau nomor spesifik `"1, 2, 3, 4, 5"`).
- Nomor yang tidak dipilih tidak akan diubah.
