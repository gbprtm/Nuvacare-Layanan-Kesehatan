# Audit & Tindak Lanjut Anti-Slop 002 (DESIGN.md & Web Interface Guidelines)

**Tanggal:** 2026-11-02
**Mode:** AFTER (`session override`) + Vercel `web-design-guidelines`
**Design Read:** Aplikasi web janji temu klinik rawat jalan untuk pasien dewasa (40–65 tahun) dan staf admin, dengan bahasa visual datar, tenang, dan kontras tinggi sesuai [DESIGN.md](../../../DESIGN.md), dial **ENERGY 1 / RHYTHM 1 / MOTION 1**.

## Daftar Temuan & Perbaikan (Nomor 11–22)

11. **[HIGH - R-37 / DESIGN.md §2 & §10] Ketidaksesuaian Token Warna, Ukuran, dan Kartu Datar**
    - **Sebab:** `public/css/style.css` sebelumnya memakai palet gelap `#0A2540`/`#00D4B2` dan bayangan kartu, belum memakai token resmi `DESIGN.md` (`--color-bg: #EEF1F6`, `--color-ink: #111418`, `--color-primary: #2563EB`, kartu datar tanpa bayangan, tinggi kontrol `48px`, radius `12px`, lebar kontainer `960px`).
    - **Status:** **SELESAI** — Seluruh token di [`public/css/style.css`](../../../public/css/style.css) diselaraskan dengan `DESIGN.md` §2, §3, §4, §7, dan §10.

12. **[HIGH - R-03 / R-25 / DESIGN.md §3] Ukuran Teks di Bawah 14px**
    - **Sebab:** `.badge` (`12.4px`), `.btn-sm` (`13.2px`), dan elemen `<small>` di tabel admin berada di bawah batas minimum `14px` untuk pengguna usia 40–65 tahun.
    - **Status:** **SELESAI** — Seluruh teks (termasuk `.badge`, `.btn-sm`, dan sel tabel) memiliki ukuran minimum `14px` dan lolos uji `contrast-check.py` WCAG AA (`5.17:1` hingga `18.47:1`).

13. **[HIGH - R-32 / R-39 / web-design-guidelines] Semantik Header, Skip Link, dan Tombol Keluar**
    - **Sebab:** Halaman belum memiliki tautan lewati navigasi (`skip-link`), `<header>` pembungkus `<nav>`, tampilan nama pengguna (`#navUserName`) di halaman pasien, dan `#logoutBtn` masih memakai `<a href="#">` alih-alih `<button type="button">`.
    - **Status:** **SELESAI** — Seluruh 11 halaman HTML di `public/` dilengkapi `.skip-link` menuju `<main id="main-content">`, landmark `<header class="site-header">`, `#navUserName`/`#navAdminName`, dan `<button type="button" id="logoutBtn">`.

14. **[HIGH - R-39 / web-design-guidelines] Atribut Formulir (`name`, `autocomplete`, `inputmode`, `spellcheck`, `:focus-visible`)**
    - **Sebab:** Input email/telepon/kata sandi belum memiliki atribut `name`, `spellcheck="false"`, `type="tel"` + `inputmode="tel"`, serta CSS input masih memakai `:focus` alih-alih `:focus-visible`.
    - **Status:** **SELESAI** — Seluruh input formulir memiliki atribut lengkap dan `:focus-visible` dengan cincin fokus `2px solid var(--color-primary)`.

15. **[HIGH - R-40 / web-design-guidelines] Render-Blocking `@import` Google Fonts**
    - **Sebab:** `@import url(...)` di baris pertama `public/css/style.css` menahan pemuatan render halaman.
    - **Status:** **SELESAI** — `@import` dihapus dari CSS dan diganti dengan `<link rel="preconnect">` serta `<link rel="stylesheet">` di `<head>` setiap dokumen HTML, ditambah `<meta name="theme-color" content="#EEF1F6">`.

16. **[MEDIUM - R-01 / R-10 / R-12 / DESIGN.md §1.5] Gradien Hero dan Blur Modal**
    - **Sebab:** `public/index.html` memakai `linear-gradient` pada `.hero` dan `public/admin/kelola-janji.html` memakai `backdrop-filter: blur(2px)`, padahal `DESIGN.md` §1.5 melarang gradien, bayangan, dan kaca buram.
    - **Status:** **SELESAI** — Gradien dan `backdrop-filter` dihapus; modal menggunakan latar padat transparan dengan `overscroll-behavior: contain`.

17. **[MEDIUM - R-31 / antislop-ui] Titik Status Dekoratif (`.brand`) dan Garis Samping Dekoratif (`riwayat.html`)**
    - **Sebab:** Titik hijau di sebelah nama klinik pada navbar tidak menandakan status nyata (*Decorative Status Dot*), dan catatan dokter di `riwayat.html` memakai `border-left` dekoratif (*Colored Left Stripe*).
    - **Status:** **SELESAI** — Keduanya dihapus dari seluruh halaman HTML dan `public/js/pasien.js`.

18. **[LOW - R-15 / R-31 / DESIGN.md §6 & §8] Sapaan, Label Tombol, dan Teks Keadaan Kosong**
    - **Sebab:** Teks tombol dan keadaan kosong belum persis mengikuti tabel `DESIGN.md` §6 & §8 (**Buat janji**, **Simpan profil**, **Selesaikan**, **Batalkan**, **Buat jadwal kontrol**, **Tambah poli**, **Tambah dokter**, serta sapaan "kamu").
    - **Status:** **SELESAI** — Seluruh label tombol, pesan kosong, pesan sesi berakhir (`401`), dan sapaan disesuaikan dengan `DESIGN.md` §6 & §8.

19. **[LOW - web-design-guidelines / DESIGN.md §8] Format Tanggal Bahasa Indonesia (`Intl.DateTimeFormat`) & Angka Tabular**
    - **Sebab:** Tanggal di tabel pasien dan admin masih ditampilkan mentah (`YYYY-MM-DD`) alih-alih format `Senin, 3 November 2026`.
    - **Status:** **SELESAI** — Ditambahkan `api.formatDate()` berbasis `Intl.DateTimeFormat('id-ID', { weekday: 'long', day: 'numeric', month: 'long', year: 'numeric' })` serta `font-variant-numeric: tabular-nums` pada tabel.

20. **[LOW - web-design-guidelines] Sinkronisasi Filter ke URL Query Params & Karakter Elipsis (`…`)**
    - **Sebab:** Filter pada `admin/kelola-janji.html` belum tersinkron dengan query parameter URL, dan teks pemuatan/placeholder masih memakai tiga titik `...` alih-alih karakter `…`.
    - **Status:** **SELESAI** — Filter `date`, `type`, dan `status` disinkronkan ke URL dengan `history.replaceState`, dan seluruh teks pemuatan/placeholder memakai `…`.
